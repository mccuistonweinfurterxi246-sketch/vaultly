# Обзор функций Vaultly (Vaultly Feature Review)

В этом документе представлен подробный список всех разработанных функций и компонентов персональной библиотеки ссылок **Vaultly**. Вы можете использовать этот обзор для анализа текущего состояния проекта и поиска идей для дальнейшего улучшения.

---

## 1. Персональная библиотека и карточки ссылок
*   **Карточки закладок (`BookmarkCard`):** Удобные интерактивные карточки, которые отображают:
    *   Полноценные обложки ресурсов (`imageUrl` из базы данных/Unsplash) на заднем фоне карточки, исключая визуальное наложение и дублирование логотипов.
    *   Фавиконку сайта (динамически подгружается через Google Favicon API) в центре стеклянного логотипа.
    *   Оптимизированный резервный фон: при отсутствии обложки `faviconUrl` размывается с аккуратным масштабом `scale-[1.5]` вместо грубого `scale-[3]`.
    *   Интерактивное масштабирование обложки при наведении (`group-hover:scale-105 transition-transform duration-500 ease-out`).
    *   Описание ресурса с поддержкой мгновенного редактирования прямо в карточке.
    *   Теги закладок с моноширинным стилем оформления.
    *   Иконку типа контента (глобус для сайтов, код для репозиториев, видео для YouTube и т.д.).
*   **Инлайн-редактирование описаний:** Возможность быстро отредактировать описание ссылки прямо на карточке, нажав на иконку карандаша. Сохранение происходит по клавише `Enter` (или клику по галочке), а отмена — по клавише `Escape`.
*   **Счетчик кликов (`clicksCount`):** При переходе по ссылке счетчик кликов автоматически инкрементируется, что позволяет в будущем отслеживать наиболее часто используемые ресурсы.

## 2. Умный импорт ссылок (`AddBookmarkModal`)
Модальное окно добавления ссылок поддерживает два режима работы:
*   **Одиночный импорт (Single Link):**
    *   При вводе URL-адреса запускается автоматическая генерация метаданных (системное автозаполнение заголовков и описаний).
    *   Автоматически определяет тип контента (`ContentType`) и предлагает теги на основе домена.
*   **Массовый импорт (Bulk Import):**
    *   Позволяет импортировать целый список ссылок, разделенных новой строкой или запятыми, с общими тегами и коллекцией.

---

## 3. Менеджер быстрых заметок (`NotesManager`)
Полноценная рабочая область для ведения текстовых заметок, которая активируется при выборе раздела «Заметки» в боковом меню:
*   **Создание в один клик:** Удобная панель создания заметок с возможностью выбора фонового пастельного цвета стикера (используются современные OKLCH-цвета).
*   **Pinterest-style сетка:** Заметки отображаются в виде красивой динамической сетки колонок (Masonry), подстраивающейся под длину текста.
*   **Умный парсинг ссылок:** Весь текст заметок сканируется на наличие URL-адресов. Любые найденные ссылки автоматически преобразуются в кликабельные HTML-ссылки с иконкой внешнего перехода.
*   **Редактирование заметок:** Поддержка изменения заголовков и содержимого существующих заметок.

## 4. Организация и фильтрация
*   **Управление коллекциями (папками):** 
    *   Возможность создавать пользовательские коллекции. При создании коллекции ей автоматически присваивается случайный приятный пастельный цвет.
    *   Сайдбар отображает количество активных закладок в каждой коллекции.
    *   При удалении коллекции все связанные с ней закладки не удаляются, а безопасно сбрасывают свою привязку (переносятся в общую библиотеку).
*   **Быстрые разделы:**
    *   `All Bookmarks` (Все закладки) — отображение всех активных закладок.
    *   `Favorites` (Избранное) — закладки с отметкой "Сердечко".
    *   `Read Later` (Прочитать позже) — закладки для последующего ознакомления.
    *   `Archive` (Архив) — архивные закладки, скрытые из общего списка.
*   **Фильтрация по тегам:** Клик по тегу в сайдбаре мгновенно фильтрует закладки во всей библиотеке.
*   **Интерактивный поиск:** Живой поиск в шапке сайта ищет совпадения по названию, описанию, тегам и URL-адресу.

## 5. Визуальный стиль и интерактивные анимации
*   **Фоновая анимация `LetterGlitch`:** На заднем фоне приложения работает стилизованная Canvas-анимация с матричными глифами и символами, которые плавно меняют цвета в темно-зеленой и бирюзовой гамме.
*   **WebGL Шейдер `FaultyTerminal`:** Вспомогательный WebGL-компонент, имитирующий олдскульный CRT-монитор с помехами, разверткой, хроматической аберрацией и дизерингом. Он умеет реагировать на движение мыши и прогресс загрузки страницы.
*   **Анимированные переходы (Framer Motion / Animate UI):**
    *   `AnimatedDialog`: Плавные, физически точные всплытия модальных окон с затуханием фона и пружинным эффектом.
    *   `HoverCard`: Интерактивный 3D-наклон (3D Tilt) карточек при движении курсора мыши.
    *   `layoutId sidebar-active`: Плавная скользящая подсветка активного пункта бокового меню.
*   **Режимы отображения списка (View Modes):** Переключатель в шапке сайта позволяет выбрать один из трех режимов отображения: Grid, Compact или List.
*   **Темная и светлая темы:** Полноценный переключатель темы (Sun/Moon) в шапке сайта с мягким изменением CSS-переменных.

## 6. Технический стек и оптимизация
*   **Стейт-менеджер Zustand:** Вся бизнес-логика сосредоточена в сторе `useBookmarkStore.ts`.
*   **LocalStorage Persistence:** Сохранение состояния библиотеки в локальное хранилище браузера (`vaultly-storage`).
*   **Оптимизация рендеринга и предотвращение утечек памяти:**
    *   Для фильтрации закладок используется хук `useMemo`, предотвращающий лишние пересчеты.
    *   Очистка слушателей событий и хуков `useSpring` при размонтировании интерактивных 3D-карточек и модальных окон.
    *   Исключение дублирования картинок путем рендеринга уникальных обложек (`imageUrl`) на заднем плане вместо повторения favicon.
